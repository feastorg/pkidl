# pkidl

PKiDL lets you design the *physical* layer of a circuit board — footprints,
placement, and layout — in Python. It is the physical-layer counterpart to
[SKiDL](https://github.com/devbisme/skidl), which covers the electrical layer
(nets, parts, and connections).

**Status:** early, under active development.
